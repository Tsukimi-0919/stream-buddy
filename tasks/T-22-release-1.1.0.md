## v1.0.0 からの変更（人が確認した結果）

- 演出中に違う種類のホットキーを押すと、すぐその演出に切り替わる（ST-27）。手動確認済み
- OBS を先に開いていたときの案内（ブラウザソースの「プロパティ」→「現在のページのキャッシュを更新」）。手動確認済み
- モデルが見つからないとき、探した場所を表示する。1段深く展開されていれば案内する。手動確認済み
- `stream-buddy.exe` にメンダコのアイコンが付いた。エクスプローラーとショートカットで確認済み
- 人が試してわかったこと（下の「README」に書く）
  - 起動中のタスクバーには、メンダコではなくコンソール（cmd や Windows ターミナル）のアイコンが出る。stream-buddy がコンソールのアプリのため
  - 前のバージョンの exe を同じ場所に上書きすると、Windows がアイコンを覚えていて、古いアイコン（Python のアイコン）のまま見えることがある。exe の中身は同じ（SHA-256 が一致した）。`ie4uinit.exe -show` を実行するか、サインインし直すと直る

# 音声認識エンジンの比較（T-06 スパイク）

## 目的

キーワード検知（FR-07）に使う音声認識エンジンを、**Vosk** と **faster-whisper** から選ぶ。
同じ発話を両方にかけて、正解率・誤検知・処理時間・CPU 時間・モデルのサイズを比べ、
結果を `docs/adr/0003-asr-engine.md` に記録する。

このフォルダのコードは比較用の使い捨てで、本体（`src/`）には含めない。
依存も `spike-asr` グループに分けてあり、本体・CI・exe には入らない。

## 準備

### 1. 依存を入れる

```
uv sync --group spike-asr
```

本体の作業に戻るときは `uv sync` で元に戻る（スパイク用のパッケージは消える）。

### 2. Vosk のモデルを手動で取得する

スクリプトは Vosk のモデルを取得しない。次の手順で手動で用意する。

1. 公式サイト <https://alphacephei.com/vosk/models> を開く
2. 「vosk-model-small-ja-0.22」の zip をダウンロードする
3. リポジトリ直下の `models/` に展開し、次の形にする

   ```
   models/
     vosk-model-small-ja-0.22/
       am/
       conf/
       graph/
       ...
   ```

`models/` は `.gitignore` 済みなので、コミットされない。

### 3. faster-whisper のモデル

初回の実行時に、Hugging Face から `models/faster-whisper/` に自動で取得する（tiny 約 78 MB、base 約 148 MB）。
外部への通信はこのスパイクに限り許可されている。2回目以降は取得済みのものを使う。

### 4. マイクとしきい値

マイクとしきい値は本体と同じ `config.toml` の `[audio]` を使う。

- マイクの名前は `uv run stream-buddy --list-devices` で調べる
- 録り終わりは音量で判定する（本体の `detect.py` と同じく、0.3 秒の無音で終わり）。
  黙っていても録り始めてしまうときは `speech_threshold_db` を上げる

## 実行

### まずマイクを使わずに動くか確かめる

```
uv run --group spike-asr python spikes/asr_compare.py --self-test
```

無音とノイズの配列を各エンジンにかける。マイクは開かない。

### 測定する

```
uv run --group spike-asr python spikes/asr_compare.py
```

1. 画面に読み上げる言葉が1つずつ表示される
2. Enter を押してから、その言葉を話す（最大 3 秒）
3. 全エンジンの判定がその場で表示される
4. 最後に結果が Markdown の表で表示されるので、`docs/adr/0003-asr-engine.md` に貼る

読み上げる言葉（各 `--rounds` 回。既定は 3 回、合計 36 回）

- キーワード：「死んだ」「やられた」「勝った」「クリア」
- キーワードではない言葉：「しんどい」「かったるい」「クリーム」「今日はいい天気」「買った」「よかった」「わかった」「なんだ」

### オプション

| オプション | 内容 |
| --- | --- |
| `--engines vosk,whisper-tiny,whisper-base` | 試すエンジン（既定は3つすべて） |
| `--rounds 3` | 読み上げの回数 |
| `--config config.toml` | マイクとしきい値の設定ファイル |
| `--self-test` | マイクを開かず、無音とノイズで動作だけ確かめる |

途中で Ctrl+C を押すと、そこまでの結果を表示して終わる。

## 注意事項

- **音声は保存しない。** 1回の発話を最大 3 秒だけメモリに持ち、全エンジンにかけたらすぐに捨てる。
  結果の表には書き起こしの文が出るので、貼る前に内容を確認すること
- 静かな部屋と、配信で実際に使うマイクで測る。ゲーム音などを流しながらの測定も、余裕があれば行う
- **Whisper の処理時間は、入力の中身によって大きく変わる。** 無音や無音に近い音では、
  条件を変えて書き起こしをやり直すため、数秒かかることがある。平均だけでなく最大も見る
- **Whisper は、雑音から存在しない文を作ることがある**（例：ノイズから「ご視聴ありがとうございました」）。
  キーワードではない言葉での誤検知の数をよく見る
- 「初回の準備」は、モデルの読み込み後に弱いノイズで1回動かした時間。上と同じ理由で、ばらつきが大きい

### Vosk の語彙

Vosk の文法（grammar）には、モデルの語彙（`models/vosk-model-small-ja-0.22/graph/words.txt`）にある単語しか使えない。
起動時に「Vosk の語彙にない単語があります」と出たら、その言葉はそのままでは認識されない。
起動時には、実際に渡す文法も表示される。

- 文法には、空白でつないだ複数の単語（句）も指定できる。「死んだ」「勝った」は 1 語では語彙にないため、
  `VOSK_PHRASES` で `"死ん だ"`・`"勝っ た"` と語彙にある単語の組み合わせにしている
- 判定は書き起こしの空白を除いてから行うので、分けて書いても「死んだ」として数えられる

### Vosk のおとりの言葉

文法がキーワードだけだと、似た音の言葉（例：「クリーム」）も一番近いキーワード（「クリア」）として認識されてしまう。
そこで `VOSK_DECOYS` に、キーワードではない「おとりの言葉」（クリーム、しんどい、かったるい、買った、よかった）を入れ、
文法の候補に加えている。

- おとりの言葉として認識されたら「検知なし」と判定する（書き起こしにはおとりの言葉がそのまま出る）
- おとりの言葉も語彙にある単語（または空白でつないだ句）で書く
- 読み上げる言葉のうち「わかった」「なんだ」は、わざとおとりの言葉に入れていない。
  文法に入れていない似た音の言葉がキーワードに寄せられて誤検知されるかを測るため
- faster-whisper にはおとりの言葉を使わない

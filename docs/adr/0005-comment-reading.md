# ADR 0005：コメントとセリフの読み上げ

- 状態：採用
- 日付：2026-11-05

## 背景

配信で使ってみて、次の 2 つの要望が出た。

- メンダコのセリフを読み上げたい
- 視聴者のコメントも読み上げたい

## 決定

- **視聴者のコメントの読み上げは作らない**。コメント読み上げの既存の道具（わんコメ、棒読みちゃんなど）にまかせる
- **メンダコのセリフの読み上げは v1.1 で作る**。PC の中で動く読み上げの道具（棒読みちゃんなど）に、ローカルの通信でセリフを渡す
  - コメントと同じ道具に渡すので、コメントとセリフの声が重ならない

## 理由

- コメントの読み上げには、次のものが必要になる。これは「外部と通信しない」「秘密情報を持たない」という今の設計の前提を変える
  - 配信サイトとの通信
  - API キーなどの秘密情報の保存
  - 知らない人の文章を声で流すことへの対策（NG ワード・長さ・連投）
- 既存の道具は、これらの対策を長く作り込んでいる
- メンダコのセリフは、配信者が書いたもの（セリフ集）だけなので、読み上げても内容の心配がない

## 結果

- `docs/requirements.md` の「やらないこと」に「視聴者のコメントの読み上げ（ADR 0005）」を加える
- v1.1 の読み上げの設計（渡し先の道具、通信の方法、`127.0.0.1` だけに送ることなど）は、別のタスクで行う

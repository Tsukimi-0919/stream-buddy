# WebSocket プロトコル（草案 v0）

> **草案**です。Phase 1 の実装で確定させ、確定後はこのファイルを正とする。
> バックエンドとページはこの仕様だけを頼りに、別々のタスクで実装できるようにする。

## 接続

- URL：`ws://127.0.0.1:<port>/ws?token=<token>`
- `<token>` は起動ごとに作るランダムな文字列（32 バイト以上、URL セーフ）
- サーバーは接続時に次を確認し、どれかが合わなければ接続を閉じる（理由は返さない）
  - `token` が一致する（比較は `secrets.compare_digest`）
  - `Origin` ヘッダーが `http://127.0.0.1:<port>` と一致する
- 同時接続はプレビューと本番を考えて **2 本まで**。超えたら新しい接続を拒否する

## メッセージの共通形式

すべて JSON テキスト。1 メッセージは 4 KB 以下。

```json
{ "v": 0, "type": "<種類>", "payload": { } }
```

- `v`：プロトコルのバージョン。合わないものは破棄
- `type`：下の一覧のいずれか。知らない種類は破棄
- 余分なキーがあるメッセージも破棄する

## ページ → サーバー

| type | payload | 用途 |
| --- | --- | --- |
| `hello` | `{ "page_version": "0.1.0" }` | 接続直後に1回だけ送る |

ページが送るのはこれだけ。それ以外を受け取ったら破棄してログに残す。

## サーバー → ページ

| type | payload | 用途 | 関連 |
| --- | --- | --- | --- |
| `speech` | `{ "speaking": true }` | 口パクの開始・終了 | FR-02 |
| `tension` | `{ "level": "calm" \| "normal" \| "high" }` | テンションの変化 | FR-04 |
| `say` | `{ "line_id": "string", "text": "string" }` | 吹き出しに表示（`text` は 80 文字以内） | FR-05, FR-06 |
| `effect` | `{ "kind": "death" \| "clear" }` | 画面演出 | FR-09 |
| `display` | `{ "background": "transparent" \| "chroma" }` | 背景の切り替え | FR-03 |

## ページ側のルール

- `text` は必ず `textContent` で表示する（SR-04）
- 知らない `type` や形の違うメッセージは無視する
- 接続が切れたら、数秒おいて再接続する（無限に速く再試行しない）

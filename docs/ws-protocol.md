# WebSocket プロトコル（v0）

> T-03 で確定した。このファイルを正とする。実装は `src/stream_buddy/protocol.py`（メッセージ）と `src/stream_buddy/server.py`（接続）。
> バックエンドとページはこの仕様だけを頼りに、別々のタスクで実装できるようにする。

## 接続

- URL：`ws://127.0.0.1:<port>/ws?token=<token>`
- `<port>` は設定ファイルの `server.port`（既定 8765、1024〜65535）。待ち受けアドレスは `127.0.0.1` 固定で変えられない
- `<token>` は起動ごとに作るランダムな文字列（`secrets.token_urlsafe(32)`）。ページの URL（`/overlay?token=<token>`）と同じもの
- サーバーは接続を受け入れる前に次をすべて確認し、どれかが合わなければ接続を受け入れずに閉じる（HTTP 403。理由は返さない）
  - `token` が一致する（比較は `secrets.compare_digest`）
  - `Origin` ヘッダーが `http://127.0.0.1:<port>` と完全一致する（`Origin` がない場合も拒否）
  - 同時接続数が 2 未満（プレビューと本番を考えて **2 本まで**）
- `Host` ヘッダーが `127.0.0.1:<port>` と一致しない接続は、上の確認より前に HTTP 400 で拒否する（DNS リバインディング対策）

## メッセージの共通形式

すべて JSON テキスト。1 メッセージは 4 KB（4096 バイト、UTF-8）以下。

```json
{ "v": 0, "type": "<種類>", "payload": { } }
```

- `v`：プロトコルのバージョン。現在は `0`。合わないものは破棄
- `type`：下の一覧のいずれか。知らない種類は破棄
- 余分なキーがあるメッセージも破棄する（`payload` の中も同じ）
- 型は厳密に扱う（例：`"0"` は `0` とみなさない）

## ページ → サーバー

| type | payload | 用途 |
| --- | --- | --- |
| `hello` | `{ "page_version": "0.1.0" }`（1〜32 文字） | 接続直後に1回だけ送る |

ページが送るのはこれだけ。サーバーは次のように扱う。

- 形の合わないメッセージ、壊れた JSON、バイナリのメッセージは破棄し、エラーの種類だけをログに残す（中身は残さない）。接続は切らない
- 4 KB を超えるメッセージを受け取ったら、close コード `1009` で接続を閉じる

## サーバー → ページ

| type | payload | 用途 | 関連 |
| --- | --- | --- | --- |
| `speech` | `{ "speaking": true }` | 口パクの開始・終了 | FR-02 |
| `tension` | `{ "level": "calm" \| "normal" \| "high" }` | テンションの変化 | FR-04 |
| `say` | `{ "line_id": "string", "text": "string" }` | 吹き出しに表示（`line_id` は 1〜64 文字、`text` は 1〜80 文字） | FR-05, FR-06 |
| `effect` | `{ "kind": "death" \| "clear" }` | 画面演出 | FR-09 |
| `display` | `{ "background": "transparent" \| "chroma" }` | 背景の切り替え | FR-03 |

サーバーは接続中のすべてのページに同じメッセージを送る（`Hub.broadcast`）。範囲外の値（例：81 文字の `text`）は、送る前のモデルの検証で弾かれる。

## ページ側のルール

- `text` は必ず `textContent` で表示する（SR-04）
- 知らない `type` や形の違うメッセージは無視する
- 接続が切れたら、数秒おいて再接続する（無限に速く再試行しない）
